# 别碰我的 NVIDIA 即时重放
[English](README.md) | **中文**

### “关闭属于用户电脑的功能并丢弃用户的内容，应当先征求用户同意。”

一个油猴脚本，使得网页在加载 Widevine CDM（用于播放受保护内容）而使 NVIDIA 即时重放被终止前先询问用户，只有授权后才能终止 NVIDIA 即时重放并播放受保护内容，防止即时重放被未经同意即自动关闭（不会自动重新打开），且丢弃已录制但未保存的内容。用户明确授权前均保持拦截状态。

给用户选择：当确实有网站需要播放 DRM 内容，用户可以先选择保存现有即时重放，并更明显地获知后续即时重放被阻止——以便播放结束后重新启用。对于有些网站即使没有受保护内容，也滥用这一功能，用户可以拒绝（并记住拒绝状态）为该网站授权。

**警告**：本脚本并非用于规避、绕过、破解 DRM 数字版权保护机制，无法解锁、解密、保存、传播任何 DRM 内容，**并不会赋予浏览器录制 DRM 加密视频内容的能力**。脚本拦截 EME 调用后，**被拦截站点上的 DRM 加密视频将无法播放**。如需加载 Widevine CDM，需要用户手动选择授权，此时即时重放会按照原有逻辑正常被站点阻止，才能播放 DRM 内容。

## 功能特性
- 在目标网站拦截 EME / Widevine 相关浏览器接口
- 两种拦截模式：`reject`（直接抛出 NotSupportedError）、`hang`（返回永不决议的 Promise）
- 允许本次会话临时放行，或永久加入放行名单
- 在网页右下角显示角标入口，或快捷键 `Alt+E`，手动强制唤起控制面板
- 主要面向基于 Chromium 的主流浏览器

## 安装方法
1. 安装油猴脚本管理器：Tampermonkey
2. 导入脚本
3. 访问网页。
